# 业火

这是 Karma Fire 的个人博客，用来记录随笔、阅读、生活片段与技术思考。

博客地址：<https://karma-fire.github.io>

## 内容

- 随笔与个人思考
- 阅读记录
- 生活记录
- 技术学习与实践

## 关于项目

本博客使用 Astro 构建，内容以 Markdown 文件维护，并采用静态页面部署。

本博客基于 [Fuwari](https://github.com/saicaca/fuwari) 模板构建，并根据个人需求进行了配置和调整。
